# 回声星 · ruin-city-3d

一颗由七块地拼成的小星球（半径 8 公里）。第一块是已经建成的城市「雾港残响」：海岸上被藤蔓吞没、断裂倾斜的高楼废墟，沿山坡叠起的雾港老城，沉在海湾里的楼群，北方山顶断顶的白塔。另外六块（戈壁大裂谷、沉没森林湿地、浮空群岛、火山熔炉区、冰原坠舰带、盐湖镜原）目前是能认出地貌的占位，等逐个开工时整块替换。

用 Three.js 0.160 写成，纯静态网页，没有构建步骤。

## 运行

任何静态文件服务器都可以，例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

（直接双击 `index.html` 不行，浏览器不允许 `file://` 加载 ES 模块。）

## 星球

- 球面分成 42 块（12 块五边形 + 30 块六边形）。7 块是模块，其余是海洋、荒原和极地冰原。
- 地块交界自然过渡：陆地与海之间是不规则的海岸线，陆地之间按组合长出山脊、干裂谷或海峡。
- 全球只有一个时钟和一套天气：各地的当地时间按经度推算，晨昏线扫过星球；几团天气云团自西向东漂移，也可以把某种天气钉在当前镜头下方的地方。
- 镜头可以从轨道一路推到街道：远处拖动是转星球，近处是绕点旋转；点地标或左侧模块列表会飞过去。
- 「环星飞艇」巡星号沿航线依次飞过七块地，在模块上空放慢。
- 新模块怎么接进来见 [`src/modules/README.md`](src/modules/README.md)。

## 玩法

- **风景**：环星巡游，以及城市里的五段自动镜头（斜阳废墟、雾港夜灯、浮空之岛、雨中沉城、白塔晨雾），每段自带时间和天气。
- **时间 / 天气**：拖动时间条或点预设；天气有晴、多云、雾、雨。
- **镜头**：全景俯瞰（拖动旋转、滚轮缩放、右键平移）、街道漫游（WASD + 鼠标拖动，Shift 奔跑；手机用左下摇杆）、搭乘电车 / 飞艇 / 渡船。
- **点击**：点建筑、地标、电车、船、飞艇、小机械会弹出信息卡，可以「靠近看看」或直接搭乘。
- **声音**：右上角打开，环境音全部由 WebAudio 现场合成。
- `H` 隐藏界面，`Esc` 退出当前镜头模式。

## 城市里的联动

| 类别 | 表现 |
| --- | --- |
| 昼夜 | 天黑后窗户按户、路灯按盏陆续亮起；灯塔转动、雾天光束更明显；废墟楼顶的航空障碍灯闪烁；白塔接缝与光环、浮岛晶体夜里更亮 |
| 天气 | 下雨时地面与墙面逐渐变湿反光，雨停后慢慢晾干；海面出现雨点涟漪；风变大，树和草摆得更厉害，雨丝被吹斜；船摇得更厉害，电车减速 |
| 行人 | 雨天有伞的人撑伞快走，没伞的人跑到最近的屋檐下躲雨，雨停再出来；夜里街上的人逐渐回家 |
| 交通 | 两列电车在七个站之间运行：进站减速、开门、候车的人上车、乘客下车走进城里、响铃出发 |
| 飞艇 | 「邮差号」巡航一圈后靠上系留塔，停靠时机头随风转向 |
| 物理 | 断楼顶上不时掉下碎石，按重力下落、弹跳并扬起尘土；附近的鸟群被惊飞，离得近时镜头会震动 |
| 生物 | 镜头靠近鸟群时鸟会惊飞；废墟里的小机械「拾遗者」在镜头靠近时会抬头看你 |
| 声音 | 风声随风力和高度变化，雨声、海浪声随离海岸的距离变化；鸟叫、电车铃、落石、雾笛都是有方位的 3D 声源 |

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/main.js` | 组装：星球、模块、镜头、界面 |
| `src/planet/sphere.js` | 星球半径、地块坐标系（平面 ↔ 球面）、三维噪声 |
| `src/planet/tiles.js` | 球面分块、模块落位、交界类型 |
| `src/planet/surface.js` | 拼接各地块高度场，生成星球地形网格 |
| `src/planet/mount.js` | 把模块的平面场景卷到球面上 |
| `src/planet/sky.js` | 全球时钟与天气、光照补丁、大气、云、海面、雨、雾 |
| `src/planet/rig.js` | 轨道到街道的镜头、巡游、搭乘、漫游 |
| `src/planet/route.js` | 环星飞艇航线 |
| `src/planet/biomes.js` | 海洋、荒原、极地的地形与配色 |
| `src/modules/ruin-city/` | 模块 1：城市（地形、建筑、生活、点击、声音、巡游镜头） |
| `src/modules/placeholders.js` | 模块 2–7 的占位地貌 |
| `src/modules/salt-mirror/` | 模块 7 盐湖镜原：镜面盐湖（kit.js 镜像几何、lake.js 三遍绘制的镜面）、列柱大道、巨环、天线阵等（structures.js） |
| `src/util.js` | 随机数、噪声、几何合并构建器、程序化贴图 |
| `vendor/` | Three.js 及所用 addons 的本地副本（MIT 许可，见 `vendor/THREE-LICENSE`） |

所有贴图都在运行时用 Canvas 画出来，没有外部美术资源。
