# 雾港残响 · ruin-city-3d

一座海岸上的奇幻 3D 城市：西边是被藤蔓吞没、断裂倾斜的高楼废墟，东边是沿山坡层层叠起的雾港老城，海湾里沉着半截高楼，北方山顶立着断顶的白塔，废墟上空漂着带瀑布的浮空岛。

用 Three.js 0.160 写成，纯静态网页，没有构建步骤。

## 运行

任何静态文件服务器都可以，例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

（直接双击 `index.html` 不行，浏览器不允许 `file://` 加载 ES 模块。）

## 玩法

- **风景**：五段自动镜头（斜阳废墟、雾港夜灯、浮空之岛、雨中沉城、白塔晨雾），每段自带时间和天气。
- **时间 / 天气**：拖动时间条或点预设；天气有晴、多云、雾、雨。
- **镜头**：全景俯瞰（拖动旋转、滚轮缩放、右键平移）、街道漫游（WASD + 鼠标拖动，Shift 奔跑；手机用左下摇杆）、搭乘电车 / 飞艇 / 渡船。
- **点击**：点建筑、地标、电车、船、飞艇、小机械会弹出信息卡，可以「靠近看看」或直接搭乘。
- **声音**：右上角打开，环境音全部由 WebAudio 现场合成。
- `H` 隐藏界面，`Esc` 退出当前镜头模式。

## 城市里的联动

| 类别 | 表现 |
| --- | --- |
| 昼夜 | 天黑后窗户按户、路灯按盏陆续亮起；灯塔转动、雾天光束更明显；废墟楼顶的航空障碍灯闪烁；白塔接缝与光环、浮岛晶体夜里更亮 |
| 天气 | 下雨时地面与墙面逐渐变湿反光，雨停后慢慢晾干；海面出现雨点涟漪；风变大，树和草摆得更厉害，雨丝被吹斜；船摇得更厉害，电车减速 |
| 行人 | 雨天有伞的人撑伞快走，没伞的人跑到最近的屋檐下躲雨，雨停再出来；夜里街上的人逐渐回家 |
| 交通 | 两列电车在七个站之间运行：进站减速、开门、候车的人上车、乘客下车走进城里、响铃出发 |
| 飞艇 | 「邮差号」巡航一圈后靠上系留塔，停靠时机头随风转向 |
| 物理 | 断楼顶上不时掉下碎石，按重力下落、弹跳并扬起尘土；附近的鸟群被惊飞，离得近时镜头会震动 |
| 生物 | 镜头靠近鸟群时鸟会惊飞；废墟里的小机械「拾遗者」在镜头靠近时会抬头看你 |
| 声音 | 风声随风力和高度变化，雨声、海浪声随离海岸的距离变化；鸟叫、电车铃、落石、雾笛都是有方位的 3D 声源 |

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/world.js` | 地形高度函数、地形网格、海面与天空着色器、时间调色板、光照、雾、雨、湿度、环境光照 |
| `src/city.js` | 断楼生成、高架残桥、摩天轮、沉没楼群、雾港小楼、码头、灯塔、系留塔、电车线与站台、白塔、浮空岛、植被 |
| `src/life.js` | 电车与乘客、行人、船、飞艇、鸟群、小机械、落石与扬尘 |
| `src/camera.js` | 自由视角、风景巡游、搭乘、街道漫游 |
| `src/interact.js` | 点击识别与信息卡 |
| `src/audio.js` | WebAudio 合成环境音 |
| `src/util.js` | 随机数、噪声、几何合并构建器、程序化贴图 |
| `vendor/` | Three.js 及所用 addons 的本地副本（MIT 许可，见 `vendor/THREE-LICENSE`） |

所有贴图都在运行时用 Canvas 画出来，没有外部美术资源。
