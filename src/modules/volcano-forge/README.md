# 模块 5：火山熔炉区

一座还在运转的远古工厂嵌在活火山的南坡上。参考埃塞俄比亚达纳基尔（硫磺泉、熔岩湖）和冰岛熔岩原（苔原熔岩、玄武岩柱、裂隙喷发）。

## 布局（局部坐标：+z 北，+x 西）

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 火山口 | (0, 260)，熔岩湖 528 米 | 横跨火山口的吊桥，大勺每 64 秒舀一勺岩浆倒进熔心台 |
| 熔心台 | 470 米 | 豁口闸门、接收池、心炉、四座热风炉 |
| 锻造大厅 | 360 米 | 拱窗长厅、锯齿屋顶、五根烟囱、转动的齿轮组、汽锤 |
| 浇铸场 | 235 米 | 发光的铸模、两台龙门吊、两座冷却塔、倒下的烟囱 |
| 守门台 | 135 米 | 门楼与两尊跪着的守卫巨像，熔岩从门下流出 |
| 熔岩河与熔岩湖 | 南面 (420, -1010) | 湖北岸是台阶状的玄武岩柱崖 |
| 西侧熔岩原 | x > 400 | 长满青苔的熔岩、一道带喷泉的裂隙 |
| 东侧硫磺泉 | (-860, -640) | 黄绿相间的泉丘和酸池，冒白汽 |

## 文件

| 文件 | 内容 |
| --- | --- |
| `terrain.js` | 高度、地表颜色、远景发光、台地剖面、河道与裂隙路径、核心地形网格 |
| `lava.js` | 流动熔岩材质、熔岩带/池/瀑布几何、热场（让附近的岩壁和墙被映红）、建筑自发光补丁 |
| `forge.js` | 工厂全部建模和会动的部件 |
| `fx.js` | 烟、蒸汽、火星、熔岩喷泉、夜间光晕（全部在着色器里按时间算） |
| `tours.js` | 风景巡游路线与「前往」落点 |
